# Procedencia de las fotografías

Las seis fotografías del catálogo se guardan en `src/main/resources/static/images/` para que la tienda funcione sin pedir imágenes a servidores externos. Son **imágenes ilustrativas**: los nombres, descripciones y precios de BikeStore son ficticios y no identifican los modelos ni las marcas fotografiadas.

Las imágenes se descargaron de las páginas gratuitas de Unsplash y se usan bajo la [licencia de Unsplash](https://unsplash.com/license), que permite copiarlas y utilizarlas en este proyecto. Se acredita a cada autor aunque la licencia no lo exige.
